# Gerenciador de Shopping

Projeto em Java desenvolvido para gerenciar lojas, produtos e estoque.

## Funcionalidades
- Cadastro de produtos
- Remoção de produtos
- Controle de estoque
- Cálculo de gastos com funcionários

## Tecnologias
- 100% Java
 
## IDE
- BlueJ, por recomendação da faculdade

## Observação
Projeto desenvolvido com suporte de ferramentas de Inteligência Artificial para auxílio no aprendizado e implementação.
